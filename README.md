# Проєкт: IQ Challenge

Онлайн-платформа з інтерактивними тестами на кмітливість, логіку та швидкість мислення.

## Виконані завдання:
1. **Тестовий блок:** Додано три повноцінні логічні запитання з варіантами відповідей.
2. **Семантика та дизайн:** Веб-сторінка повністю побудована за стандартами HTML5 та стилізована за допомогою сучасних CSS-властивостей у стилі Dark Mode.
3. **Адаптивність:** Додано спеціальне медіаправило `@media (max-width: 600px)` для комфортного проходження тестів зі смартфонів.
4. **Інтерактивність:** За допомогою JavaScript реалізовано миттєву перевірку вибраної відповіді з візуальним відображенням результату.

## Стек технологій:
- HTML5 (Семантична структура)
- CSS3 (Чуйна верстка, Media Queries)
- JavaScript (DOM manipulation)
